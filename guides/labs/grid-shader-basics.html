01 The big idea

You are not drawing thousands of line meshes. You draw one big quad (two triangles). Every pixel on that quad runs a tiny program — the fragment shader — that asks:

“Am I sitting on a grid line right now? If yes, paint gray. If no, paint dark.”

Your project already decided: ground is XZ, height is Y (docs/grid-system.md). So “where on the floor?” means the pixel’s world.x and world.z.

Analogy: the quad is a blank sheet of graph paper. The fragment shader is you, holding a ruler, deciding for each tiny square of the sheet whether to ink a line.

02 Pass world position to the fragment shader

The vertex shader already turns each corner into clip space with u_worldViewProjection (that’s gl_Position — for the GPU’s triangle rasterizer).

Grid math must not use gl_Position. That space is warped by the camera. You need the floor’s real coordinates. So:

  1. In the vertex shader, multiply position by u_world (or pass world pos another way).
  2. Write it to an out vec3 v_worldPos.
  3. In the fragment shader, read in vec3 v_worldPos — the GPU interpolates it across the quad.
// vertex (idea)
vec4 world = u_world * a_position;
v_worldPos = world.xyz;
gl_Position = u_worldViewProjection * a_position;

// fragment later uses:
float x = v_worldPos.x;
float z = v_worldPos.z;
Checkpoint in your head: fragment shader knows “this pixel is at world (x, y, z) on the floor.” Your current stub doesn’t pass that yet — that’s the first real change.

03 Color by world.x (prove it works)

Before any grid math, prove the varying works. Map world X to a color. Drag across the canvas — you’re scrubbing a fake “pixel’s” world X.

Debug · color from world.x
// temporary fragment — if the floor becomes a smooth gradient, world pos is flowing
outColor = vec4(v_worldPos.x / 20.0, 0.2, 0.4, 1.0);

In the engine: if the floor is one flat color still, the varying isn’t connected. If it’s a gradient that moves when you orbit the camera, you’re good.

04 Divide the world into cells

Pick a cell size, e.g. tileSize = 1.0 (one world unit per cell). Then world.x / tileSize is “how many cells from the origin.”

Example: if world.x = 3.7 and tileSize = 1, you’re in cell 3, a bit past the start of that cell.

Number line · cells
float cell = v_worldPos.x / u_tileSize;
// cell = 3.7 means: past 3 whole cells, 0.7 into the next

05 fract = leftover inside the cell

fract(x) (GLSL spelling of “fractional part”) keeps only the part after the decimal. fract(3.7) = 0.7. It always lands in [0, 1).

So no matter how far you are from the origin, fract(world.x / tileSize) tells you: how far through the current cell am I? (0 = left edge, 0.5 = middle, almost 1 = right edge)

Sawtooth · fract
float f = fract(v_worldPos.x / u_tileSize);
// resets every cell → repeating pattern for free
This is the core trick of almost every procedural grid. One function call turns infinite world space into “position inside a tile.”

06 Threshold → stripes (not lines yet)

If fract < 0.1, paint line color — you get a thick stripe on the left side of every cell. Good for learning; not a centered thin line yet.

1D · stripe mask
float f = fract(x / tileSize);
float onLine = f < thickness ? 1.0 : 0.0;

07 Near an edge → thin lines

Grid lines sit on cell boundaries (where fract is near 0, or near 1 — which is the same boundary as the next cell’s 0).

Measure distance to the nearest edge of the cell, then ask if that distance is small:

1D · edge lines
float f = fract(x / tileSize);
float distToEdge = min(f, 1.0 - f);
float line = distToEdge < halfWidth ? 1.0 : 0.0;
Read it out loud: “How close am I to a cell boundary? If close enough, I’m on a line.”

08 Do X and Z → a grid

Same formula on world.z. You’re on a line if either axis says so (max is fine for a first version).

2D · your first grid
float fx = fract(v_worldPos.x / u_tileSize);
float fz = fract(v_worldPos.z / u_tileSize);
float lx = min(fx, 1.0 - fx) < halfWidth ? 1.0 : 0.0;
float lz = min(fz, 1.0 - fz) < halfWidth ? 1.0 : 0.0;
float grid = max(lx, lz);

Toggle “X only” / “Z only” to see each family of lines. “Both” is the floor grid.

09 Shader you can paste

This is a complete first fragment (plus the vertex idea). Jaggy edges are OK. Matches your axes: ground XZ. 

// --- vertex ---
in vec4 a_position;
uniform mat4 u_worldViewProjection;
uniform mat4 u_world;
out vec3 v_worldPos;

void main() {
  vec4 world = u_world * a_position;
  v_worldPos = world.xyz;
  gl_Position = u_worldViewProjection * a_position;
}

// --- fragment ---
precision highp float;
in vec3 v_worldPos;
uniform float u_tileSize;   // e.g. 1.0
uniform vec3 u_bgColor;    // dark
uniform vec3 u_lineColor;  // light gray
out vec4 outColor;

void main() {
  float halfWidth = 0.04; // tweak: smaller = thinner lines

  float fx = fract(v_worldPos.x / u_tileSize);
  float fz = fract(v_worldPos.z / u_tileSize);

  float lx = min(fx, 1.0 - fx) < halfWidth ? 1.0 : 0.0;
  float lz = min(fz, 1.0 - fz) < halfWidth ? 1.0 : 0.0;
  float grid = max(lx, lz);

  vec3 color = mix(u_bgColor, u_lineColor, grid);
  outColor = vec4(color, 1.0);
}
mix(a, b, t) = lerp. When grid is 0 you get background; when 1 you get line color. That’s how you turn a 0/1 mask into pixels.

Engine checkpoint

Floor quad visible → world gradient debug works → this shader shows a grid (even if stair-stepped). That’s success for “basics.” Then continue floor-grid.md for mesh / program wiring.

10 Why it’s jaggy (short preview)

A hard < test is a binary cut. When the camera tilts, a line covers part of a pixel — but we still paint 100% or 0%. That sparkles.

Soft fix (good enough for a while): replace the hard test with smoothstep, and make the soft width depend on fwidth — “how much does this value change between neighboring pixels?”

Hard cut vs soft edge
// soft version of one axis (idea only)
float dist = min(fx, 1.0 - fx);
float aa = fwidth(v_worldPos.x / u_tileSize);
float lx = 1.0 - smoothstep(halfWidth, halfWidth + aa, dist);
Stop here for now. Soft edges like this are the “tutorial grid.” Golus’s article goes much further (phone-wire fade, Moiré, etc.). You do not need that to ship a usable floor.
