00 What “good” means

A texture grid gets thinner with distance and fades to a gray that matches line coverage (how much of each cell is line). Naive smoothstep + fwidth tutorials often use constant pixel width lines, which fill the horizon with line color. Golus wants UV-space thickness and clean AA — like a texture, but sharper.

You already know: vertex vs fragment, attributes, uniforms, world vs clip space. Everything below is fragment math on a world-space UV (usually world.xz / tileSize).

01 One line from a UV

Treat one UV axis as a number line. Near 0 we want “on the line.” abs(uv * 2) folds both sides so left and right look the same — multiply by 2 so lineWidth means total width, not half-width.

1D · abs fold 
float lineUV = abs(uv.x * 2.0);
// lineUV == 0 at the line center; grows as you leave it
uv abs(uv×2) threshold (lineWidth)

Drag the scrubber: below the green threshold you’re “inside” the line. Hard cutoffs alias — next we soften the edge.

02 Soft edges with smoothstep

smoothstep(edge0, edge1, x) remaps x from the range [edge0, edge1] into [0,1] with an S-curve, and clamps outside. Put the soft band around your line width so the edge spans roughly one pixel of AA.

1D · hard cut vs smoothstep 
float line = smoothstep(lineWidth + lineAA, lineWidth - lineAA, lineUV);
// high when close to center (lineUV small), soft falloff over ±lineAA
hard step smoothstep AA band
Why ×1.5 later? Golus often uses lineAA = uvDeriv * 1.5 because smoothstep’s S-curve is steeper than a linear ramp — 1.5px of smoothstep ≈ 1px of linear AA in perceived softness.

03 Repeating: frac → triangle

frac(uv) (GLSL fract) wraps into [0,1) — a sawtooth. Turn that into a triangle peaked at every integer so every cell boundary is a line center:

1D · wave morph 
float gridUV = 1.0 - abs(frac(uv.x) * 2.0 - 1.0);
// peaks = 1 at integers (line centers), valleys = 0 mid-cell
current wave line mask

Click through the stages. The final 1.0 - abs(frac*2 - 1) puts peaks on the integers so line 0 matches the single-line case.

04 Two axes → a grid

Run the same line math on X and Y. Combining with max or + double-counts crossings. Golus uses a premultiplied alpha blend: draw X lines, then composite Y on top — same as lerp(gx, 1, gy).

2D · combine modes 
float grid = lerp(grid2.x, 1.0, grid2.y);
// == grid2.x * (1 - grid2.y) + grid2.y
// black-on-white form: grid = 1.0 - grid2.x * grid2.y  (with smoothstep edges swapped)

05 Screen derivatives

ddx(v) / ddy(v) are how much v changes to the neighboring pixel horizontally / vertically. fwidth(v) ≈ |ddx| + |ddy|. That tells you: “how many UV units fit in one screen pixel?” Use it so the soft edge stays ~1 pixel wide no matter zoom or tilt.

floor view · fixed AA vs derivative AA 
float2 uvDeriv = fwidth(uv);       // UV change per pixel
float2 lineAA  = uvDeriv * 1.5;
// far away / grazing: uvDeriv grows → thicker soft band in UV → still ~1px on screen
Top of image = near camera · bottom = horizon (higher uvDeriv)
Mental model: derivatives answer “how zoomed is this UV at this pixel?” Big derivative ⇒ one pixel covers a lot of UV ⇒ lines must be softer / handled carefully.

06 UV width vs pixel width

UV width: lines have constant size in world/UV — they get thinner on screen with distance (perspective). Pixel width: drawWidth = uvDeriv * pixels — constant screen thickness; horizon fills with line color.

UV-space width
pixel width

Golus wants the left look (perspective), without the aliasing UV-width usually gets far away.

07 Phone-wire AA

Never let a line thinner than ~1 pixel on screen — clamp thickness up, then fade opacity by how much you inflated it: coverage *= lineWidth / drawWidth. That preserves perceived thickness while killing sparkle.

single line into distance 
float drawWidth = max(lineWidth, uvDeriv);
float line = smoothstep(drawWidth + lineAA, drawWidth - lineAA, lineUV);
line *= saturate(lineWidth / drawWidth);  // ← the magic fade
Bonus: lineWidth = 0 fades out completely — the fade term goes to 0. Try dragging width to 0 with “clamp + fade” on.

08 Clamp draw width to 0.5

On a grid, phone-wire alone fades the horizon to black — wrong. A pixel can cover many cells, but you only draw one line pair. Fix: also cap how fat the drawn line can get: clamp(lineWidth, uvDeriv, 0.5), then fade.

Why 0.5? When the soft line spans half a cell, the average coverage across the cell is ~0.5 — same number you divide by when fading. Cap at 1.0 and the average isn’t 1.0, so the fade math goes dark.

horizon brightness 
float2 drawWidth = clamp(lineWidth, uvDeriv, 0.5);
grid2 *= saturate(lineWidth / drawWidth);
target distant gray ≈ lineWidth (coverage) Watch the horizon strip — only “cap @0.5” matches it

09 Kill Moiré on purpose

When uvDeriv > 1, a whole cell is smaller than a pixel — interference patterns. Golus cheats (on purpose): fade each axis toward a solid lineWidth once derivatives pass 0.5, fully solid by 1.0.

interference fade 
grid2 = lerp(grid2, lineWidth, saturate(uvDeriv * 2.0 - 1.0));
// starts blending at deriv=0.5, done at deriv=1.0

10 Wide lines via inversion

The 0.5 clamp means you never draw a line wider than half a cell. For lineWidth > 0.5, flip the problem: draw the gap (width 1 - lineWidth) and invert the result. Same math, full range 0→1.

lineWidth past 0.5 
bool invert = lineWidth > 0.5;
float targetWidth = invert ? 1.0 - lineWidth : lineWidth;
// … pristine math on targetWidth …
grid = invert ? 1.0 - grid : grid;

Slide past 0.5 with inversion on — the floor fills correctly up to solid white at 1.0.

11 length() vs fwidth()

fwidth = |ddx| + |ddy| overestimates on diagonals (taxicab distance). length(float2(ddx, ddy)) is Euclidean. Golus prefers length for this shader; Quilez sometimes uses max(|ddx|, |ddy|) for filtered procedurals. Compare:

diagonal stress test 
float4 uvDDXY = float4(ddx(uv), ddy(uv));

12 Final recipe

Put this in your floor fragment shader (HLSL-ish; swap names for GLSL).

pristineGrid(uv, lineWidth) → coverage
float pristineGrid(float2 uv, float2 lineWidth) {
  float4 uvDDXY = float4(ddx(uv), ddy(uv));
  float2 uvDeriv = float2(length(uvDDXY.xz), length(uvDDXY.yw));

  bool2  invertLine  = lineWidth > 0.5;
  float2 targetWidth = invertLine ? 1.0 - lineWidth : lineWidth;
  float2 drawWidth   = clamp(targetWidth, uvDeriv, 0.5);
  float2 lineAA      = uvDeriv * 1.5;

  float2 gridUV = abs(frac(uv) * 2.0 - 1.0);
  gridUV = invertLine ? gridUV : 1.0 - gridUV;

  float2 grid2 = smoothstep(drawWidth + lineAA, drawWidth - lineAA, gridUV);
  grid2 *= saturate(targetWidth / drawWidth);                          // phone-wire fade
  grid2 = lerp(grid2, targetWidth, saturate(uvDeriv * 2.0 - 1.0)); // moiré kill
  grid2 = invertLine ? 1.0 - grid2 : grid2;

  return lerp(grid2.x, 1.0, grid2.y);                                // premul combine
}
  1. UV — world position / cell size (same axes as your floor).
  2. Derivatives — how much UV changes per pixel (AA scale).
  3. Invert if wide — keep target width ≤ 0.5.
  4. drawWidth — at least 1px (uvDeriv), at most half a cell.
  5. Triangle wave — repeating line distance field.
  6. smoothstep — soft mask.
  7. Fade — target/draw so inflated lines don’t look fat.
  8. Moiré lerp — solid coverage when cells < pixel.
  9. lerp axes — premultiplied composite of X and Y lines.
  10. Color — mix(bg, lineColor, coverage).
